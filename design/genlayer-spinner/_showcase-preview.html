Beacon

A loading spinner built from the GenLayer mark itself — held fixed and undistorted at the centre, exactly as the brand guidelines require. A Kinetic Cobalt arc carries the motion around it.

SVG + CSS No JavaScript 1.8s loop 16–128px

Palette and usage rules sourced from genlayer.com/brand.

Ceramic Node #F5F5F5 the mark, unaltered on both grounds Carbon Void #070707

The idea

"The GenLayer mark is a static system variable. To maintain absolute legibility and visual authority against the UI, it must remain uncompromised and isolated from other data streams." GenLayer brand guidelines · genlayer.com/brand

Most brand marks get bent, split, or spun into a loading animation because it's the easiest way to add motion. GenLayer's own guidelines rule that out directly — so this spinner takes the opposite approach: the mark never moves at all.

The mark

Fixed at the centre, always upright, fill and proportions exactly as published. It is never rotated, scaled unevenly, or split into pieces — nothing about its geometry changes, ever.

The arc

A single Kinetic Cobalt stroke orbits around the mark at a fixed distance, sized to leave clear space on every side. It is the only part of the design that moves.

The pulse

A faint breathing scale on the mark, timed to the arc's revolution, keeps the whole mark feeling alive without ever distorting its shape.

This also matches how GenLayer already uses Kinetic Cobalt elsewhere: never as the mark's own linework, only as a fill or accent — the app icon is the mark in white on a Cobalt chip, not a blue mark. The spinner borrows that exact logic instead of inventing a new one.

Small sizes

The arc's 5-unit stroke reads as a smudge below about 28px, so the compact variant drops it and lets the mark's own bold, solid-filled geometry carry the small sizes on its own.

Spec

ElementColorMotion
Mark, light ground Carbon Void #070707 Fixed position · breathing scale 1–0.95
Mark, dark ground Ceramic Node #F5F5F5 Same, opposite fill
Orbiting arc Kinetic Cobalt #110FFF 360° sweep, 1.8s linear, ~26% of ring visible

The arc's radius (46 units in a 100-unit viewBox) is set so its full sweep clears the mark's bounding box on every side — the two never overlap at any rotation. No <defs> or id attributes anywhere, so the markup repeats freely on one page.

Under prefers-reduced-motion: reduce, the arc's rotation stops entirely and it becomes a static ring at reduced opacity; the mark drops to an opacity-only fade — no scale, no movement of any kind on the mark itself. role="status" and a <title> announce the loading state.

If GenLayer's brand kit has an official vector source for the mark, the d attribute on .gl-spinner__mark is the only thing that needs swapping — this build reconstructed the path by eye from the published mark images, straight edges only, matching the mark's own construction. Everything else (the arc, the pulse, the theming) is independent of that path.
